# ShopFlow

Локальный демо-магазин на Flask: 18 товаров, русский / английский / украинский интерфейс, корзина, избранное, просмотренные товары и панель управления. Палитра — мягкие мята, лайм и персик; фотографии товаров хранятся локально в WebP.

## Запуск

```powershell
cd "$env:USERPROFILE\Desktop\ShopFlow"
.\start.ps1 -Port 5001
```

Магазин: http://127.0.0.1:5001/ · Панель: http://127.0.0.1:5001/admin

После изменения шаблонов или Python-кода перезапустите сервер. Если порт занят, выберите другой через `-Port`. Серверу требуется запись в `instance/` и `static/products/uploads/`.

## Установка

Python 3.12 или новее:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m flask --app app:create_app upgrade-demo
.\.venv\Scripts\python.exe -m flask --app app:create_app create-admin
.\start.ps1 -Port 5001
```

Не заменяйте существующий `.env`. Команда `upgrade-demo` добавляет таблицы и поля, сохраняя заказы и учётные записи. Для установки точных версий проверенного окружения используйте `requirements.lock.txt`; он включает также тестовые зависимости.

## Возможности

- Поиск, фильтры, сортировка, цвета в каталоге, история просмотров, сравнение характеристик.
- Фото и варианты товара, увеличение изображения, закреплённая покупка, отдельные цены комплектаций камеры.
- Корзина и оформление с расчётом цены на сервере. Цена, название и вариант фиксируются в заказе.
- Редактор товаров с загрузкой обложки и галереи, изменением порядка фотографий и цен вариантов.
- Автоматический перевод названий и описаний через MyMemory; передаются только тексты товара. Сбой перевода сообщает об ошибке сохранения.
- Выполнение заказа отдельно от оплаты, история новых изменений статуса. Старые переходы не восстанавливаются.
- Сводка последних 100 заказов: отменённые исключены из суммы, новые и обрабатываемые включены в «К выполнению».
- Демонстрационные отзывы и подписка; реальные письма и доставка не выполняются.

## Конфигурация

| Переменная | Назначение |
| --- | --- |
| SECRET_KEY | Секрет сессий и CSRF; минимум 32 символа для production |
| DATABASE_URL | Пустое значение — `instance/shopflow.db`; поддерживается PostgreSQL |
| APP_ENV | `development` для локального запуска |
| BASE_URL | Адрес для платёжных перенаправлений, должен соответствовать вашему порту |
| STRIPE_SECRET_KEY / STRIPE_WEBHOOK_SECRET | Необязательные тестовые ключи Stripe; реальные платежи отключены |
| TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID | Необязательные уведомления о заказах |

Без Stripe работает демо-оформление без списания денег. Telegram, если подключён, отправляет сведения заказа и покупателя. `.env`, база и загруженные фотографии исключены из Git — храните их резервные копии отдельно.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
```

Тесты используют отдельные временные базы; реальный каталог и заказы не изменяются. Подробности структуры и уборки: [docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md). Последняя проверка: [docs/qa/CURRENT_CHECKS.md](docs/qa/CURRENT_CHECKS.md).

## Ограничения

Это демо-проект. Проверка PostgreSQL, настоящие платежи, доставка, возвраты, аккаунты покупателей и производственное развёртывание требуют отдельной работы. Для публикации нужны HTTPS, резервные копии, мониторинг, управляемые миграции и сервер production вместо встроенного Flask.
