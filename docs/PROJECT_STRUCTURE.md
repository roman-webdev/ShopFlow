# Структура проекта

| Путь | Что хранится |
| --- | --- |
| app.py | Приложение Flask, модели, API, администрирование и команды базы |
| product_translation.py | Перевод и кэширование текстов товаров |
| seed.py / demo_catalog.json | Исходный каталог; повторное заполнение сохраняет последующие правки |
| templates/ | Общий шаблон, магазин, панель, редактор, вход и заказ |
| static/store.js | Каталог, варианты, корзина, оформление и сравнение |
| static/admin-ui.js | Поиск заказов и товаров, фото и превью редактора |
| static/i18n.js / translations.js | Переключение языка и словари |
| static/select-menu.js / motion.js | Выбор из списков и движение интерфейса |
| static/*.css | Базовый стиль и последовательные слои оформления; порядок подключения важен |
| static/products/photos/ | Фото товаров; colorways/ — изображения вариантов |
| static/products/uploads/ | Загруженные фотографии, не включаются в Git |
| tests/ | Изолированные проверки приложения и переводов |
| docs/qa/ | Текущие результаты проверки и снимки |
| docs/archive/ | Прежние отчёты и описание, оставлены для справки |
| instance/ | Рабочая база данных, не включается в Git |
| .venv/ | Локальное окружение, не включается в Git |
| requirements.txt | Зависимости сайта |
| requirements-dev.txt | Зависимости сайта плюс инструменты тестирования |
| requirements.lock.txt | Полное проверенное окружение с точными версиями |
